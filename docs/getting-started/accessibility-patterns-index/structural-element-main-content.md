    This content added 2026-04-27. Check for updated guidance at: <a href="https://wave.webaim.org/api/docs?format=html#main" target="_blank">https://wave.webaim.org/api/docs?format=html#main</a>

    > ### WAVE Category
    > Structural Elements
    > ### WAVE Error
    > Main content
    > ### What It Means
    > A `<main>` element or main landmark is present.
    > ### Why It Matters
    > The `<main>` element or role="main" attribute identifies the main content for the page. This facilitate page semantics and navigation.
    > ### What To Do
    > Ensure the element surrounds and defines page main content.
    > ### The Algorithm... in English
    > A `<main>` element or role="main"is present.
