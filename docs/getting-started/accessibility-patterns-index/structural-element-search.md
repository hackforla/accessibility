## WAVE Tool Reference

??? Info "Click to see WAVE Tool Reference"

    This content added 2026-04-27. Check for updated guidance at: <a href="https://wave.webaim.org/api/docs?format=html#search" target="_blank">https://wave.webaim.org/api/docs?format=html#search</a>

    > ### WAVE Category
    > Structural Elements
    > ### WAVE Error
    > Search
    > ### What It Means
    > An ARIA search landmark is present.
    > ### Why It Matters
    > The search landmark identifies the search area within the page and facilitates keyboard navigation to the search area.
    > ### What To Do
    > Ensure the search landmark is implemented properly and surrounds the search area of the page.
    > ### The Algorithm... in English
    > An element has role="search".
    > ### Standards and Guidelines
    > - [1.3.1 Info and Relationships (Level A)](https://webaim.org/standards/wcag/checklist#sc1.3.1)
